# CLOUD CHAT – MASTER PROJECT CONTEXT

Last Updated: 18 November 2026

## 1. Project Overview

We are building Cloud Chat, a cloud-based messaging application using Flutter and Firebase.

The goal is to develop a modern, scalable messaging application with user discovery, real-time conversations, media sharing and document sharing.

Development approach:
- Android-first.
- Cloud-first architecture.
- Clean separation of UI, services and models.
- Beginner-friendly, step-by-step implementation.
- Avoid unnecessary abstractions and duplicate code.

## 2. Technology Stack

- Flutter – Mobile application.
- Dart – Programming language.
- Firebase Authentication – Phone number authentication.
- Cloud Firestore – Database and real-time updates.
- Firebase Storage – Profile pictures, images, videos and documents.
- Firebase Cloud Messaging – Push notifications.

## 5. Current Data Architecture

We are separating private and public user information.

### users/{uid}

Private information:
- uid
- phoneNumber
- profileCompleted
- createdAt
- updatedAt

### publicProfiles/{uid}

Discoverable information:
- uid
- displayName
- username
- photoUrl
- profileCompleted
- createdAt
- updatedAt

### usernames/{username}

Username registry:
- uid
- username

Usernames must be unique.

### conversations/{conversationId}

Conversation metadata managed by the conversation model and service.

- Deterministic conversation ID using sorted participant UIDs.
- Participant information.
- Last message preview.
- Last message timestamp.
- Conversation metadata.

The exact field names must follow the existing implemented ConversationModel. Do not introduce duplicate or conflicting fields.
